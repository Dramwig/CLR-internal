用户授权：2026-11-08；预算25 GPUh，包含全部smoke、失败、加载和重启。优先R4→R2→R1→R3。不改M8a/M71/Idea A冻结文件。

## 数据与训练
沿用M71生成器、counts和group划分。reader_train按group哈希取4000组（不更改生成器counts）；原/CF均提取。reader_val固定哈希200组，cal_A300、cal_B1000；最终test沿用M8a固定500组。smoke训练100组、val20，不触碰test，≤900秒。
R4：冻结Qwen3，decoder块7/16/25/34输出，取direct答案生成前最后8个已知prompt token；固定正交512维投影。仅A1/A4监督，标签为消息私有值。无生成的答案token、无私有原文进入reader。
R2：逐消息均匀不放回抽8/36层；各记录内部边界独立抖动{-1,0,+1} token；投影P[:,:128]乘独立Bernoulli(.9)/.9对角矩阵。分布公开，部署抽样与攻击EOT独立。抽样保持同一消息/面板一致。低秩投影的容量差异另报为限制。
R3：全36层记录均值+末8token，固定P[:,:128]。R2/R3存储投影记录均值、边界修正及末8token，不存全KV。R4存512维状态。
三seed11/22/33；各自冻结原M71 reader主体，训练新源适配器（随机初始化，输入层按维度调整）、训练集均值方差。A1正/负平衡，负例三种错值按epoch循环，避免旧seed33负例缺口；A4四选项。此数据修复与架构改变共同发生，不能将全部提升归因架构。
训练最多12epoch，AdamW lr3e-4、batch128，val A1/A4等权NLL选checkpoint，patience3。所有设置在最终test前锁定；不按test选模型。

## 审计与校准
新设计只用A1/A4（各半抽样），期望值仅由x_pub公开置换/公开z与可见commitment反推。R1沿用原A1–A4分布与冻结主体/适配器，k=1/4/16/64；其他设计k16。
cal_A按task温度缩放；cal_B1000 clean分别按design/seed/k独立定1%/5%有限样本split-conformal上分位阈值。随机读取cal与test抽样独立。原模型原k16门限保留为参考。conformal仅在clean可交换条件下有边际保证，对自适应攻击不作保证。

## 扰动与指标
E1/E2固定M8a原f盲层/池化零空间，所有设计共享定义；R3自身未读层为空不算作经验成功。E3对每设计/seed自适应，目标receiver CF logp−λ审计NLL；随机设计对公开分布EOT，优化看不到最终抽样。eps=.01/.03/.1/.3，PGD50/200步、λ=.1/1/10，val20先估算；预算若需缩矩阵须在test前明确锁定并报告。早停使用独立攻击验证抽样，报告抽样不参与优化/停止/选候选。
主失效=clean非CF目标→CF目标且未报警，固定分母500；附目标且接受及clean-correct条件指标、识别率与cleanFPR，三seed、group bootstrap10000。候选只凭攻击可得的独立EOT评分与目标命中选择，两个α共享候选。R1理论参考是条件独立单问拒绝事件下的p_accept(1)^k，并非均值NLL规则定理。
审查≤8000字节、(a)–(f)、≤3表，保存全部CSV/图/成本/冻结与上游核验。
