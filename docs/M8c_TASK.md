## C候选与部署隔离
同一组/设计/seed的λ候选按「receiver目标命中优先、攻击侧selection NLL最低、目标logp最高」选取；绝不按报告检测结果选λ。部署问题采用运行启动生成、攻击不可见的独立随机key，保存供复现。EOT每步重抽16问，selection为两组固定16问，PGD成功可提前停止（报告实际步数），未成功最多200步。
二分先由小到大探测预设ε括号，找到成功上界后再二分；保存所有失败、原已目标、右截尾和独立报告面板是否识别。有限PGD不证明失败ε不可行，因此称「搜索发现的扰动成本」，不能冒称数学最小值或鲁棒性保证。最终二分深度与预算矩阵由val20吞吐锁定。
