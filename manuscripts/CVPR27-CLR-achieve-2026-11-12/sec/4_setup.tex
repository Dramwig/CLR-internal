\section{Experimental Setup}
\label{sec:setup}

\paragraph{Sources and data.} We use released CODI checkpoints on GPT-2 and LLaMA-3.2-1B-Instruct with six latent steps. We fixed an inference protocol (fp32, batch 1, original cohort padding) agreeing with the official evaluation on 95.3\% of GSM8K test problems for GPT-2 (bf16 replay: 99.9\%) and 98.9\% for LLaMA. Reader training uses 20k (GPT-2) and 6.8k (LLaMA) GSM8k-Aug training problems, which the source models were trained on; evaluation uses GSM8K test problems re-split by problem ID into cal (500) and test (1005), deduplicated by 13-gram overlap against the source training corpus. This creates a seen/unseen shift: at the last step, early-exit accuracy is 82\% on reader-train problems versus 42\% on test. SVAMP and ASDiv serve as unseen-dataset pools (CODI-GPT-2 accuracy 43\% and 55\%).

\paragraph{Baselines.} B0: question-only (latent zeroed). B3: two-layer MLP over the current state, template, and option features, one per question type; B3-prefix: B3 over the latent prefix; B3-multi: one MLP for all types. B4: scalar latent reward model (LTO-style~\cite{lto}). B6: single-layer cross-attention probe per type (options or learned queries attend to the latent sequence) with exposure and parameters no smaller than B3. B5a: zero-shot Patchscope into the source model. B5c: LatentQA-style verbalizer~\cite{pan2024latentqa}---a two-layer projection injects latents into frozen Qwen3-1.7B with LoRA ($r{=}16$), trained on the same typed QA data and calibrated identically. All learned readers are trained with 3 seeds, model-selected on reader-val NLL, and frozen before test access. Intervals are 95\% problem-level (or group-level) bootstrap intervals over the three-seed mean.
